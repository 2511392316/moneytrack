# 记账 PWA(原型)

手机端快速记账,数据全部存在本机浏览器里,离线可用,不需要账号和网络。

## 在手机上打开

方式一(推荐,可加到主屏):

1. 电脑上进入本目录,执行 `python -m http.server 8080 --bind 0.0.0.0`
2. 用 `ipconfig` 查到电脑局域网 IP(形如 `192.168.1.5`)
3. 手机浏览器打开 `http://192.168.1.5:8080`
4. 浏览器菜单选「添加到主屏幕」,之后像 App 一样从桌面打开

方式二:把整个 `moneytrack` 目录拷到手机,用文件管理器打开 `index.html`。

两种方式的数据互不相通(浏览器按来源隔离),选一种就一直用它。

## 数据存放在哪

- 优先 IndexedDB;若当前环境不支持(例如直接以 `file://` 打开),自动回退到 localStorage
- 清理浏览器数据 / 卸载浏览器会一并清掉,所以要定期用「账户 → 导出 JSON」备份
- 金额一律按整数「分」存储,显示两位小数,不会出现浮点误差

## 功能

- 记账:支出/收入切换、大类(第一行)+小类(第二行)
- 算式键盘(支持 `12+8.5`)、选账户、备注;常用分类自动置顶
- 明细:按日分组、按月/类型/账户/分类筛选、点按修改或删除
- 统计:按月看收入/支出/净现金流、支出构成饼图(点扇区或图例下钻小类)、账户余额
- 账户:新增/编辑/删除账户(类型可自填,如新办的卡)、余额实时计算、转账、余额校准
- 分类管理:收入/支出各自的大类与小类增删改名
- 数据:导出 JSON(完整备份)/ 导出 CSV(给 Excel)/ 导入覆盖恢复(导入前自动备份)






## 说明

- 转账只影响账户余额,不计入收入支出统计
- 信用卡等负债型账户初始余额可填负数,净资产 = 各账户余额之和
- 手记账与真实余额难免有偏差,用「余额校准」填入实际余额,差额自动记录
